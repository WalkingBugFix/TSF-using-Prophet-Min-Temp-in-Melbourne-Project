# TSF-using-Prophet-Min-Temp-in-Melbourne-Project
The primary objective of this project is to analyze and forecast daily minimum temperature trends in Melbourne using historical weather data. We aim to provide meteorological and environmental stakeholders with valuable insights to support climate monitoring, and enhance preparedness for temperature-related variations and events.
